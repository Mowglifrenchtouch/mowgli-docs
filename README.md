## 🛠️ Développement local

```bash
npm install

# Lancer les deux langues (FR par défaut)
npm start

# Lancer uniquement en français
npm run start:fr

# Lancer uniquement en anglais
npm run start:en
```

Puis ouvrir : [http://localhost:3000/mowgli-docs/](http://localhost:3000/mowgli-docs/)

Pour tester le build de production :

```bash
npm run build
npm run serve
```
