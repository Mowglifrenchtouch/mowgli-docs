## 🧩 Créations de Juditech3D

### 🔧 Support Modulaire V2 — Raspberry Pi + GPS + Alimentation

Système modulaire conçu pour intégrer facilement les composants électroniques dans le Yardforce 500B.

**Caractéristiques :**
- Modularité complète — adaptez selon vos besoins
- Compatible : Raspberry Pi 3/4, cartes ZED-F9P / Ardusimple, UM960, UM980/982, alims DC/DC
- Fixation à vis ou inserts
- Modules interchangeables entre support RPi et support GPS
- Version vierge personnalisable incluse

| Module | Description |
|--------|-------------|
| Support Raspberry Pi 3/4 | Fixation à vis ou insert |
| Support carte GPS | Ardusimple + compatibles, avec adaptateur UM960/UM980/982 |
| Support alim DC/DC LM2596 | Fixation à vis ou insert |
| Support alim DC/DC XL4016E1 | Fixation à vis ou insert |
| Support alim DC/DC XL4015 | Fixation à vis ou insert |
| Support alim DC/DC USB | — |
| Module vierge | Personnalisable selon vos besoins |

🔗 [Modèle V1](https://makerworld.com/models/603899) — V2 disponible prochainement

## 🧩 Créations de Pepeuch

### 📦 Bloc support RPi + GNSS + DC/DC + F9P (kit complet)

Kit tout-en-un pour Yardforce 500B :
- Raspberry Pi
- uBlox F9P (UART et USB)
- DC/DC 5A
- Antenne GNSS HA901A à l'intérieur du châssis (`X=0.295`, `Y=0`)
- Rondelles de calage 2mm et 4mm

🔗 [Modèle MakerWorld](https://makerworld.com/fr/models/1362541-bloc-support-rpi-gnss-dcdc-f9p-yardforce-500b#profileId-1407557)

---

### ⚙️ Adaptateur moteur SA → châssis Classic 500B

Adaptateur pour monter les moteurs de roue des séries SA (réducteurs plus fiables) sur le châssis Classic 500B.

:::warning Modification irréversible
Cette modification **entraîne la perte de garantie** — vous devrez percer le châssis avec une scie-cloche de Ø 40mm.
:::

Impression recommandée en **ABS ou PETG** (PLA possible mais déconseillé).

🔗 [Modèle MakerWorld](https://makerworld.com/en/models/1337197-yarforce-motor-adapter-sa-on-classic-500b#profileId-1376751)
