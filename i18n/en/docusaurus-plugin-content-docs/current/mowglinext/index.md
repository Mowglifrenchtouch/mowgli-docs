# 🚀 Mowglinext

:::info Under design
**Mowglinext** is the next generation of the Mowgli project, currently **in active design phase**. The complete tutorial will be available soon.
:::

---

## ℹ️ What is Mowglinext?

Mowglinext is a complete redesign of the Yardforce mower robotisation project, created by **cedbossneo** (original author of Mowgli). Modernised architecture, distinct from V1 and V2.

Official website: <a href={links.mowglinext.website} target="_blank">**mowgli.garden**</a>
